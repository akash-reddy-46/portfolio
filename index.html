Lawyer Document Pipeline

JaaGa.AI · Backend · OCR · AWS Lambda
  • Problem Lawyers were manually scanning, naming and indexing 500+ legal documents/month — slow, error-prone and a hiring bottleneck.
  • Approach Designed an event-driven ingest pipeline: S3 upload → Lambda OCR → structured MongoDB record, with PM2-managed workers for retries and a bash/WinSCP fallback for legacy uploads.
  • Impact 75% reduction in manual effort, 99.2% OCR accuracy, and zero data-loss incidents in 12 months of operation.
Node.js AWS Lambda S3 MongoDB PM2 Bash

Property Documents Automation

JaaGa.AI · Document Generation · Templating
  • Problem Ops team spent hours per deal stitching property agreements, leases and ownership records by hand — with frequent copy-paste errors.
  • Approach Built a templating engine backed by MongoDB + Google Sheets-as-source-of-truth, with a Jira webhook trigger and S3-stored generated PDFs.
  • Impact Cut document-creation time by 80% and removed an entire manual review step from the property workflow.
Node.js Google Sheets API AWS MongoDB Jira

Payments & Reconciliation Platform

JaaGa.AI · Cashfree · Idempotent retries · Webhooks
  • Problem Legacy billing was losing payments to flaky gateway responses and missing webhooks — 2.8% failure rate on real money.
  • Approach Designed an idempotent retry layer with exponential backoff, signed-webhook verification, dead-letter handling and a daily reconciliation job against Cashfree’s settlement API. Stakeholder notifications via Teams, Slack and Google Chat.
  • Impact Failure rate dropped to 0.3%, ₹50L+ monthly volume processed cleanly, and finance closes books a full day earlier.
Node.js Cashfree API MongoDB AWS Webhooks Slack/Teams

Data Scraping & Analytics Pipeline

JaaGa.AI · ETL · PM2 workers · MongoDB
  • Problem Business decisions were blocked on manual data pulls from multiple sources with no history and no alerting on breakage.
  • Approach Built a fault-tolerant scrape → clean → store pipeline with PM2-managed workers, structured retries, schema validation on ingest, and health-check alerts on failure.
  • Impact Replaced a 4 hr/day manual job with an automated pipeline; gave the team a queryable MongoDB layer for analytics dashboards.
Node.js Web Scraping MongoDB AWS PM2 Bash

Workflow Automation Hub

JaaGa.AI · Internal platform · Webhooks
  • Problem Engineers, ops and finance were duplicating work across Jira, Sheets, Slack, Teams and Google Chat — and notifications were inconsistent.
  • Approach Built a small internal event-bus / webhook router so any service can fan out notifications and updates to the right channel, with rate-limiting and retry on transient failures.
  • Impact ~70% fewer manual steps in cross-team workflows and one canonical place to audit who got notified, and when.
Node.js Jira API Google Sheets Slack / Teams / Chat Webhooks
